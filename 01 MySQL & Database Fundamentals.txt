Introduction to Databases

A database is an organized collection of data that can be easily accessed, managed, and updated. It helps in storing large amounts of information in a structured manner so that it can be retrieved efficiently whenever required.

Before databases, data was stored in files, which made searching and updating data difficult. Databases solve this problem by providing structured storage and quick access.

Real-Life Examples
• Bank systems storing customer details
• School systems storing student records
• E-commerce websites storing product and order details

Example (Conceptual Table)

ID	Name	Age
1	Ravi	21
2	Anu	22

This table represents a simple database structure.

History of Databases
The evolution of databases has gone through several stages:
1. File System (Before DBMS)
• Data stored in files
• Difficult to manage and update
• High redundancy

2. Hierarchical Database (1960s)
• Data organized like a tree structure
• One parent → many children

3. Network Database (1970s)
• More flexible than hierarchical
• Many-to-many relationships

4. Relational Database (1980s – Present)
• Data stored in tables (rows & columns)
• Most widely used model today

5. Modern Databases
• NoSQL (MongoDB, Firebase)
• Cloud databases



DBMS and its Features

A DBMS (Database Management System) is software that allows users to create, manage, and manipulate databases.


Examples of DBMS
• MySQL
• Oracle
• SQL Server


Features of DBMS
• Data Storage & Management
Stores large amounts of data efficiently
• Data Security

Protects data using authentication and permissions
• Data Integrity

Ensures accuracy and consistency
• Data Sharing

Multiple users can access data simultaneously
• Backup & Recovery

Prevents data loss
• Reduced Redundancy
Avoids duplication of data


Disadvantages of DBMS
Despite many advantages, DBMS has some limitations:
• High Cost

Installation and maintenance can be expensive
• Complexity

Requires trained professionals
• Performance Overhead
Slower for small applications

• Security Risks
If not properly managed, data can be exposed


RDBMS and its Features

An RDBMS (Relational Database Management System) is a type of DBMS where data is stored in the form of tables and relationships are established between them.

Key Concepts
• Table (Relation) → Collection of rows and columns
• Row (Tuple) → Record
• Column (Attribute) → Field

Example

Student Table
ID	Name	Course
1	Ravi	BCA
2	Anu	BBA

Features of RDBMS
• Table-based Structure
• Relationships using keys (Primary Key, Foreign Key)
• Data Integrity Constraints
• Normalization support
• SQL support for queries

Introduction to MySQL as RDBMS

MySQL is one of the most popular open-source RDBMS used for managing relational databases.

Why MySQL?
• Easy to use
• Open-source (free)
• Fast and reliable
• Widely used in web applications

Basic Example (SQL Commands)

-- Create database
CREATE DATABASE school;

-- Use database
USE school;

-- Create table
CREATE TABLE student (
    id INT,
    name VARCHAR(50),
    age INT
);

-- Insert data
INSERT INTO student VALUES (1, 'Ravi', 21);

-- View data
SELECT * FROM student;


Where MySQL is Used
• Websites (WordPress, Facebook - earlier)
• Banking systems
• E-commerce platforms


Note:
• A database stores structured data
• DBMS manages and controls databases
• RDBMS organizes data in tables with relationships
• MySQL is a widely used RDBMS with SQL support


Points to remember

• Database = Organized data
• DBMS = Software to manage data
• RDBMS = Table-based DBMS
• MySQL = Popular RDBMS
