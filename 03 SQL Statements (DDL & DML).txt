Types of SQL Statements
SQL (Structured Query Language) is used to interact with databases and perform various operations such as creating tables, inserting data, and retrieving information. SQL statements are broadly classified into different types based on their functionality. 

The main categories include 

• DDL (Data Definition Language), 
• DML (Data Manipulation Language), 
• DQL (Data Query Language), and 
• DCL (Data Control Language). 

DDL is used to define the structure of the database, DML is used to manipulate the data stored in the database, DQL is used to retrieve data, and DCL is used to control access permissions.

Example:

-- DDL
CREATE TABLE student(id INT, name VARCHAR(50));

-- DML
INSERT INTO student VALUES (1, 'Ravi');

-- DQL
SELECT * FROM student;


Revision of DDL Commands

DDL (Data Definition Language) commands are used to define and manage the structure of database objects such as tables and databases. These commands include CREATE, ALTER, DROP, and TRUNCATE. They do not deal with the data directly but instead define how the data is organized.

Explanation
• CREATE → Creates database or table
• ALTER → Modifies table structure
• DROP → Deletes database or table
• TRUNCATE → Removes all records quickly

Example:

CREATE TABLE student (
    id INT,
    name VARCHAR(50)
);

ALTER TABLE student ADD phone INT;

TRUNCATE TABLE student;

DROP TABLE student;


DML Statements – INSERT
The INSERT statement is used to add new records into a table. It allows users to insert one or more rows of data into a table. The values must match the data types of the table columns.

Explanation
INSERT is essential for storing data into the database after the table is created.

Examples:
✔ Insert all values:

INSERT INTO student VALUES (1, 'Ravi', 21);

✔ Insert specific columns:

	INSERT INTO student (id, name) VALUES (2, 'Anu');


DML Statements – UPDATE
The UPDATE statement is used to modify existing records in a table. It allows updating one or multiple rows based on a condition.

Explanation
The WHERE clause is very important; without it, all records will be updated.

Examples:
✔ Update specific record:

UPDATE student
SET age = 22
WHERE id = 1;

✔ Update multiple records:

UPDATE student
SET age = 20;


This updates all rows.

DML Statements – DELETE

The DELETE statement is used to remove records from a table. It deletes rows based on a specified condition.


Explanation
Using DELETE without a WHERE clause removes all records but keeps the table structure.

Examples:
✔ Delete specific record:

DELETE FROM student
WHERE id = 1;


✔ Delete all records:

DELETE FROM student;


Note
•	DDL → Defines structure (CREATE, ALTER, DROP, TRUNCATE)
•	DML → Manipulates data (INSERT, UPDATE, DELETE)
•	INSERT → Adds data
•	UPDATE → Modifies data
•	DELETE → Removes data


Points to remember
•	Always use WHERE clause in UPDATE and DELETE to avoid data loss
•	INSERT must match column data types
•	DDL changes structure, DML changes data
