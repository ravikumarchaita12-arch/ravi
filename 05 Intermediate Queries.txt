1. SELECT with Aggregate Functions
Explanation
Aggregate functions perform calculations on multiple rows and return a single value.

Common Functions:
• SUM() → total
• AVG() → average
• MAX() → highest value
• MIN() → lowest value
• COUNT() → number of rows


Query:

SELECT AVG(salary) AS avg_salary FROM employee;

Output:
avg_salary
42500

Query:

SELECT MAX(salary), MIN(salary) FROM employee;


Output:
MAX(salary)	MIN(salary)
60000	28000

3. Wildcards / Pattern Matching
Explanation
Wildcards are used with the LIKE operator to search for patterns.
Symbols:
•	% → any number of characters
•	_ → single character


Query:

SELECT * FROM employee WHERE name LIKE 'R%';


Output:
emp_id	name	age	salary	dept_id
101	Ravi	25	30000	2
109	Raj	31	52000	1


Query:


SELECT * FROM employee WHERE name LIKE '_a%';



Output:
emp_id	name	age	salary	dept_id
106	Sara	27	45000	2
109	Raj	31	52000	1

1. SELECT with GROUP BY Clause
Explanation
The GROUP BY clause is used to group rows that have the same values in a specified column. It is usually combined with aggregate functions like SUM(), AVG(), COUNT().

It helps answer questions like:
• What is the average salary in each department?
• How many employees are in each department?


Query:

SELECT dept_id, COUNT(*) AS total_employees
FROM employee
GROUP BY dept_id;


Output:
dept_id	total_employees
1	3
2	4
3	3


Query:

SELECT dept_id, AVG(salary) AS avg_salary
FROM employee
GROUP BY dept_id;



Output:
dept_id	avg_salary
1	50666
2	34500
3	45000

2. SELECT with GROUP BY and HAVING Clause
Explanation
• WHERE filters rows before grouping
• HAVING filters groups after grouping

Use HAVING when working with aggregate conditions.

Query:

SELECT dept_id, AVG(salary) AS avg_salary
FROM employee
GROUP BY dept_id
HAVING AVG(salary) > 40000;


Output:
dept_id	avg_salary
1	50666
3	45000

Query:

SELECT dept_id, COUNT(*) AS total_employees
FROM employee
GROUP BY dept_id
HAVING COUNT(*) >= 3;


Output:
dept_id	total_employees
1	3
2	4
3	3


3. SELECT with BETWEEN Clause
Explanation
The BETWEEN clause is used to filter values within a range.

It is inclusive (includes both start and end values).

Query:

SELECT * FROM employee
WHERE salary BETWEEN 30000 AND 50000;


Output:
emp_id	name	age	salary	dept_id
101	Ravi	25	30000	2
102	Anu	28	40000	1
103	Kiran	30	50000	3
104	Meena	26	35000	2
106	Sara	27	45000	2
107	Amit	29	48000	3
110	Pooja	26	37000	3


Query:
SELECT name, age FROM employee
WHERE age BETWEEN 25 AND 28;


Output:
name	age
Ravi	25
Anu	28
Meena	26
Sara	27
Pooja	26


Key Differences (Very Important for Students)

Clause	Purpose
GROUP BY	Groups rows
WHERE		Filters rows before grouping
HAVING		Filters groups after grouping
BETWEEN		Filters range of values

• Find departments with average salary > 45,000
• Count employees with salary between 30k–40k
• Group by age instead of department
